## Run Strategy: Getting the Most From Every Trip

### Set Incremental Distance Goals

Top community players don't chase 20k on run one. The player in the 20k distance footage set staged goals — first a new biome at 12k, then 20k — and crafted a new vehicle after each attempt. Each failed run still earns salvage, so treat every trip as progress.

### Practical Run Checklist

- **Fuel full?** Always top off before launching, and carry tank upgrades
- **Parts refreshed?** Re-craft between long attempts using new salvage
- **Route planned?** Know where the next biome starts so you don't waste fuel wandering
- **Weapons loaded?** A stalled rig surrounded by zombies ends runs early
- **Goal set?** Have one specific milestone per session

### Watch for Biome Repeats

One quirk reported by players: biomes can repeat beyond certain distances, so the terrain at 15k might resemble earlier zones. Don't panic if the landscape looks familiar — your distance counter keeps climbing even through recycled environments.
