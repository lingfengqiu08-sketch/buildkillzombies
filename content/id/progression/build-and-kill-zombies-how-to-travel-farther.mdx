## Strategi Run: Memaksimalkan Setiap Perjalanan

### Tetapkan Tujuan Jarak Bertahap

Pemain komunitas teratas tidak mengejar 20k pada run pertama. Pemain dalam rekaman jarak 20k menetapkan tujuan bertahap — pertama biome baru di 12k, lalu 20k — dan membuat kendaraan baru setelah setiap percobaan. Setiap run yang gagal tetap menghasilkan suku cadang, jadi perlakukan setiap perjalanan sebagai kemajuan.

### Checklist Run Praktis

- **Bahan bakar penuh?** Selalu isi penuh sebelum berangkat, dan bawa upgrade tangki
- **Suku cadang disegarkan?** Buat ulang di antara percobaan panjang menggunakan suku cadang baru
- **Rute direncanakan?** Ketahui di mana biome berikutnya dimulai agar tidak membuang bahan bakar untuk berkeliaran
- **Senjata dimuat?** Rig yang mogok dikelilingi zombie mengakhiri run lebih cepat
- **Tujuan ditetapkan?** Miliki satu milestone spesifik per sesi

## FAQ

**Apa kendaraan terbaik untuk menempuh jarak lebih jauh di Build and Kill Zombies?**
Tidak ada satu mobil "terbaik" — pemain komunitas merekomendasikan build yang mengutamakan tangki bahan bakar dengan ram yang kuat. Pemain yang mencapai 20k+ membangun ulang rig mereka berkali-kali, melakukan iterasi alih-alih menyempurnakan satu desain.

**Bagaimana cara mendapatkan lebih banyak bahan bakar di Build and Kill Zombies?**
Tukarkan kode COMMUNITY untuk Small Tank gratis, upgrade kapasitas tangki sebagai prioritas pertamamu, dan hindari idle yang boros. Kehabisan bahan bakar adalah penyebab kegagalan run panjang yang paling banyak dilaporkan.

**Seberapa jauh kamu bisa bepergian di Build and Kill Zombies?**
Pengalaman pemain menunjukkan run yang mencapai 20.000 studs dan lebih, dengan biome panas dimulai sekitar 12k. Pemain ambisius terus memecahkan rekor seiring suku cadang baru terbuka.

**Apa syarat 1.000 studs untuk kode IAMPRO?**
Kamu harus memiliki jarak terbaik minimal 1.000 studs sebelum kode IAMPRO akan memberikan hadiah 5.000 cash — satu alasan lagi mengapa progresi jarak awal langsung memberikan keuntungan.
